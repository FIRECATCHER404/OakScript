# OakScript implementation state

This file tracks OakScript 0.8.1. The runner includes the expanded language, graphics/audio/compute APIs, library discovery and source debugging. Native compilation covers CPU, 2D/3D graphics, audio, compute and the advanced constructs described in docs/NATIVE_COMPILATION.md. The full original language/graphics roadmap and full-language native coverage still have remaining work. Older verification entries below are historical snapshots.

## Implemented

Raygame physics correction on **2026-10-09**: resting contacts now cache accumulated unilateral normal and Coulomb friction impulses, solve velocity constraints before integration and after position projection, use stable clipped box face patches and symmetric pressure resultants for centered support, and suppress low-speed restitution. Long stalls remain bounded at 0.25 seconds.
