# Acorn Run

A small forest platformer written entirely in OakScript. Collect all ten acorns, avoid thorns and beetles, and reach the grove at the right end of the trail. You have three hearts. Flags save your respawn position, and collected acorns survive a hit.

Run with OakScript 0.3.1 or newer:

```powershell
oakscript C:/Users/thero/Documents/OakScript/examples/games/acorn-run/main.oak
```

The portable build is in `dist/AcornRun/`. Double-click `Play.cmd` there, or run its included `oakscript.exe main.oak`. It contains the self-contained runner and all game files, and needs no SDK, package installation, or network connection. Keep the folder together. A Vulkan-capable graphics driver is required.

| Input | Action |
| --- | --- |
| Enter | Start, resume, or play again |
| A / D or Left / Right | Move |
| Space, W, or Up | Jump; release early for a shorter hop |
| P | Pause / resume |
| R | Restart the entire trail |
| Escape | Quit |

The scenery and character use `fill_poly`; text uses `load_font`, `measure_text`, and `draw_text2`. Input uses `key_down` and `key_pressed`. Movement, collisions, jump buffering, coyote time, game states, camera motion, collectible tracking, checkpoints, enemies, and drawing helpers are ordinary imported Oak libraries. The runner contains no game-specific native implementation.

`lib/physics.oak` and `lib/game.oak` can run without a window. Verify gameplay with:

```powershell
oakscript test.oak
```

The checks include a complete trail using the actual movement/jump update loop, without teleporting or assigning collected scores. `lib/trail-test.oak` is only a test controller; `main.oak` uses keyboard input.

The 960 x 640 layout has a fixed logical size. Audio is not implemented. Automated simulation, SDL event integration, and Vulkan captures are verified; physical keyboard/window interaction remains unverified because the Computer Use helper is unavailable.
